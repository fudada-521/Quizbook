# 高项千题闯关 · 答题练习

基于《江山老师题库 · 千题闯关》（软考·信息系统项目管理师 综合知识）整理的本地刷题程序。

## 使用方法

直接 **双击打开 `index.html`**（或拖入浏览器），无需安装任何环境、无需联网。

## 功能

| 功能 | 说明 |
|---|---|
| 百词斩式节奏 | 点选项 → **滑入答案解析页**：答对短暂停留后自动进入下一题（带圆环倒计时）；答错则停在解析页细读，读懂再手动「继续」 |
| 自动跳转可调 | 设置中可选 1 / 1.6 / 2.5 / 4 秒或不自动；倒计时中点「暂停自动跳转 ✋」即可留下继续读解析 |
| 按章节练习 | 26 个章节顺序模式，每章显示进度与正确率 |
| 随机练习 / 智能推进 | 全库随机抽题；智能推进优先出未做过的题 |
| 错题本 | 答错自动收录，支持"错题重练"和单轮"回顾错题" |
| 答题卡 | 顶栏"答题卡"可跳转任意一题 |
| 键盘快捷键 | `A`–`D` 选项、`Enter` 确认/下一题、`←`/`→` 翻题 |
| 选项乱序 | 设置中开启，防止死记答案位置 |
| 进度保存 | 自动保存在浏览器 localStorage，可在设置中导出/导入 JSON 备份 |

## 题库数据

- 来源：`../江山/题/千题闯关.pdf`（扫描版，经 macOS Vision OCR 识别 + 结构化解析）
- 规模：**2210 道四选一单选题**，覆盖第 1~26 章（含英语题、计算题章节）
- 数据文件：`questions.js`（纯数据，可自行修改）

## 已知限制

1. 题目文字来自 OCR，个别字词可能有识别误差（如"的/钓"混用），不影响理解和作答。
2. 少数题干涉及网络图、表格的计算题（原书为图片），文字描述可能不完整，遇到明显残缺的题目可忽略。
3. 多问题小题（一题干带多个空）已尽量拆分或剔除，被剔除的原题号在题库中形成少量编号间断。
4. 如需扩充案例题（《案例金色考点及真题解析.pdf》），可另行处理。
